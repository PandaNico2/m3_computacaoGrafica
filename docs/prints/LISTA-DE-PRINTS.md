# Prints para o relatório

Salve cada print nesta pasta (`docs/prints/`) com o nome indicado.
Como tirar no Mac: **⌘ Command + Shift + 4**, depois **Espaço**, e clique na janela do jogo (captura só a janela).

| Nº | Arquivo | Onde entra | Como tirar |
|---|---|---|---|
| 1 | `print1-exemplo.png` | Figura 1, seção 6.1 | Rodar o jogo (F5) e apertar **E** para mostrar a fase de exemplo |
| 2 | `print2-colapso.png` | Figura 2, seção 6.3 | Apertar **E** de novo, depois **R**; com a fase ainda pela metade (células escuras), apertar **Espaço** para pausar |
| 3 | `print3-fase-pronta.png` | Figura 3, seção 6.3 | Esperar a fase terminar (HUD mostra "concluída") ou apertar **I** |
| 4 | `print4-teste-terminal.png` | Figura 4, seção 6.4 | No terminal, dentro da pasta do repositório, rodar `/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --script res://tests/teste_wfc.gd` e capturar a parte final, com a linha "Sucesso: 20/20" |
| 5 | `print5-fase-impossivel.png` | Figura 5, seção 7.2 | Apertar **R** (e **I**) até aparecer uma fase com um buraco largo demais para pular |

Dica: nos prints do jogo, deixe o HUD (barra de cima) aparecendo, porque ele mostra a seed e o número de células indefinidas.
